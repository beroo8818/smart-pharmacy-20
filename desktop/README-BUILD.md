# دواء — دليل بناء النسخة Desktop (Windows)

## المتطلبات
- جهاز Windows 10 أو أحدث
- صلاحيات تثبيت البرامج
- اتصال إنترنت **مرة واحدة فقط** لتنزيل الحزم

## خطوات البناء

### 1) تثبيت Node.js
حمّل وثبّت Node.js 20 LTS من:
https://nodejs.org/en/download

تحقق من التثبيت بفتح PowerShell وكتابة:
```powershell
node -v
npm -v
```

### 2) فتح مجلد المشروع
انسخ مجلد `desktop/` إلى جهازك (مثلاً سطح المكتب)، ثم في PowerShell:
```powershell
cd $HOME\Desktop\desktop
```

### 3) تثبيت الحزم
```powershell
npm install
```
قد يستغرق 3-5 دقائق. ستظهر تحذيرات (طبيعية).

> إذا فشل `better-sqlite3` بسبب الـ native build:
> ```powershell
> npm install --global windows-build-tools
> npm rebuild better-sqlite3
> ```

### 4) تجربة التطبيق قبل التغليف (اختياري)
```powershell
npm run dev
```
سيفتح التطبيق في نافذة Electron. سجّل الدخول بـ:
- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

### 5) إنتاج setup.exe
```powershell
npm run build:win
```
بعد دقيقتين تقريبًا، ستجد الملف في:
```
desktop\release\Dawa-Setup-1.0.0.exe
```

## توزيع الملف
- انقل `Dawa-Setup-1.0.0.exe` إلى جهاز المستخدم.
- اضغط مرتين على الملف. اختر مسار التثبيت.
- سيُنشأ اختصار "دواء" على سطح المكتب وفي قائمة Start.
- لا يحتاج إنترنت بعد التثبيت.

## أين تُحفظ البيانات؟
على جهاز كل مستخدم:
```
C:\Users\<اسم_المستخدم>\AppData\Roaming\Dawa\dawa.db
```
- النسخ الاحتياطية التلقائية: `...\Dawa\backups\`
- لن تُحذف عند إلغاء التثبيت.

## أول تشغيل
1. افتح البرنامج من الاختصار.
2. سجّل دخول بـ `admin / admin123`.
3. اذهب إلى **الإعدادات** وغيّر كلمة المرور فورًا.
4. أضف باقي المستخدمين من صفحة **المستخدمون**.

## مشاكل شائعة
| المشكلة | الحل |
|---|---|
| التطبيق لا يفتح بعد التثبيت | احذف من `%APPDATA%\Dawa` وأعد التثبيت |
| `better-sqlite3` فشل البناء | شغّل `npm rebuild better-sqlite3` |
| الواجهة فارغة | تأكد أن `dist/` بُنيت قبل electron-builder |

## النسخ الاحتياطي اليدوي
من داخل التطبيق: **الإعدادات → نسخة احتياطية → تصدير**.
يحفظ ملف `.db` يمكن استعادته لاحقًا أو نقله لجهاز آخر.
