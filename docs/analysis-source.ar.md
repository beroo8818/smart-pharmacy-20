# اختيار مصدر التحليل وتخفيف التقارير

أعلى القائمة الجانبية يوجد اختيار «مصدر التحليل والتقارير» للتحليل المستمر في الويب والديسكتوب:

- «كل الرفعات المحفوظة»: آخر رصيد معروف لكل صنف وموقع، مع تاريخ الاستهلاك والحركات الفعلية. الأصناف الغائبة من ملف جديد تظل بآخر بيانات معروفة؛ الغياب ليس صفرًا ولا أمر حذف.
- «آخر ملف محفوظ فقط - للتجربة»: قراءة أحدث رفعة مسموحة للحساب حسب وقت الحفظ، دون ضم أصناف ملفات أبريل وغيرها. تظل الحركات الفعلية المرتبطة بالأصناف ضمن الحساب. الملف الجزئي لا يثبت اكتمال مخزون المستشفى.

الاختيار مرشح عرض محلي، لا يمسح الرفعات أو القاموس أو الحركات، ولا يغير صلاحيات الحساب. الأشهر المختارة لنافذة الاستهلاك ليست مرشحًا لحذف الأصناف القديمة. عند اختيار رفعات محددة صراحة في الكود، لها الأولوية على تفضيل العرض العام. صفحات البيانات الخام والتقارير القديمة التي لا تستخدم التحليل المستمر تظل مستقلة عن هذا المرشح.

للاختبار بملف الأصناف العشرة: احفظه بعد المعاينة، ثم اختر «آخر ملف محفوظ فقط - للتجربة»، وافتح مركز التقارير. اختر النطاق المطلوب؛ عشرة أصناف في عشرة فروع ومخزن تعني 110 سجلات قبل تجميع المواقع، وليس عشرة صفوف بالضرورة.

جداول مركز التقارير والتنبيهات تعرض 100 صف في الصفحة، بأزرار السابق والتالي. البحث يعمل على كل البيانات المحملة، والتصدير والطباعة يشملان كل الصفوف المطابقة للمرشحات. طباعة آلاف الصفوف تظل عملية كبيرة؛ يفضل تحديد الصيدلية أو الصنف أو التصدير إلى CSV عند الحاجة.

تحسين قراءة الديسكتوب يعيد استخدام نتيجة فحص صلاحية الموقع داخل استعلام القراءة نفسه فقط؛ القراءة التالية تعيد فحص الصلاحيات، فلا يوجد تخزين دائم لقرار السماح.

التحديث المحلي يتطلب إغلاق البرنامج وإعادة فتحه. لا يتطلب إعادة استيراد ملف محفوظ، ولا حذف قاعدة البيانات. تحسين هذه المسارات ليس إثباتًا بأن كل الشاشات اجتازت تجربة تشغيل فعلية على أجهزة المستشفى.
