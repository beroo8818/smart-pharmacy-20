# Dawa 1.1.0 - Local Pilot Preview

نسخة تجريبية محلية من دواء، وليست نشرًا مركزيًا أو اعتمادًا للتشغيل الفعلي بالمستشفى.

## التنزيل والتشغيل

- المستخدم العادي: نزل Dawa-Portable-1.1.0.zip، واستخرج المجلد بالكامل، ثم افتح Dawa.exe.
- للنقل بعد الاستخدام: أغلق البرنامج وانقل المجلد كله بما فيه DawaData، وليس exe وحده.
- Dawa-Setup-1.1.0-x64.msi مثبت تجريبي بديل. أكمل مستخدم واحد المعالج، وتطابقت ملفات exe وapp.asar والاختصارات. تشغيل النسخة المثبتة وإزالتها لم يختبرا بالكامل؛ محاولة الإزالة من بيئة الفحص منعت من الاتصال بالخدمة.
- الدليل العربي المرفق 18 صفحة، وملف SHA256SUMS.txt يحتوي بصمات التنزيلات.
- ملفات Source code التي ينشئها GitHub تلقائيًا للمطورين، وليست بديلًا عن ملف البرنامج المحمول.

## ما تغير

- صلاحيات تفصيلية من 50 بندًا مع نطاق الصيدليات، وشاشة متابعة تأخر تحديث الفروع.
- فترات منصرف بالأيام ومنع التكرار والتداخل، وفصل المسجل عن التقدير.
- تقارير المخزن والفروع والمستشفى، ومساعد مخزون وسجل قرارات مشترك العرض.
- حفظ قرارات الديسكتوب في SQLite لتدخل النسخ والاسترجاع، مع استيراد صريح للقديم.
- استرجاع قاعدة مستقل مع فحص ونسخة أمان واستبدال بعد إعادة التشغيل.
- تغليف Windows مستقل، وأيقونة دواء، وZIP قابل للنقل.

## التحقق والحدود

نجح 170 اختبار ويب و16 اختبار واجهة ديسكتوب و154 فحص SQLite و113 فحص PostgreSQL و25 فحص استرجاع و42 فحص سيناريو مدير ومخزن وفرعين. فتحت النسخة المحمولة بعد النقل، وأعيدت فحوص الخلفية من مواردها المغلفة. طابقت الملفات الـ100 داخل MSI ملفات البناء بعد استخراج CAB للقراءة فقط.

الاختبارات معزولة ببيانات تدريبية، لا تمثل قبولًا ميدانيًا. بعض الشاشات القديمة ما زالت مختلفة. ترقيات قاعدة الويب الستة مجهزة لكنها غير مطبقة على القاعدة الحية. لا توجد مزامنة بين الأجهزة أو تشغيل مركزي مفعل، ولا خدمة تنبيه والبرنامج مغلق.

البناء غير موقع بشهادة ناشر. تعذر فحص ICE الكامل وبُني MSI بخيار skip-ice الصريح؛ لا تعطل حماية Windows. يجب تغيير كلمة مرور admin الافتراضية قبل إدخال بيانات فعلية. لا تشمل التنزيلات بيانات المستشفى أو حساباتها.
