# Dawa 1.1.1 - Navigation and Hospital Supply Review

إصدار تجريبي محلي. لم يفعل خادم مستشفى أو يطبق ترحيلات قاعدة الويب الحية.

- قائمة مشتركة في الويب والديسكتوب: الشغل اليومي والتقارير أعلى، والإدارة والبيانات وكلمة المرور والنسخ الاحتياطي أسفل داخل قسم قابل للفتح. يظل ظهور البنود خاضعًا للصلاحيات.
- تصحيح توصية الشراء بالويب: يعتمد الاستكمال على فجوة رصيد المستشفى «المخزن + الفروع»، ولا يضاف نقص التوزيع مرة ثانية بسبب احتياطي المخزن. تنبيه مراجعة للتوزيع موجود في النسختين.
- لم يتغير هدف التغطية الافتراضي أو سجلات الجرد والحركات بسبب التعديل. لم تنفذ قائمة الدعم؛ هي رأي وتصميم مبدئي موضح في docs/support-proposal.ar.md.
- نسخة ZIP كاملة الملفات قابلة للنقل. فكها بالكامل وافتح Dawa.exe؛ بعد الاستخدام انقل المجلد كاملًا بما فيه DawaData بعد الإغلاق.
- Release هو صفحة نشر ملفات البرنامج على GitHub، وليس برنامجًا آخر أو خدمة مطلوبة لتشغيل النسخة المحمولة.

البرنامج غير موقع بشهادة ناشر، والمثبت يحتاج اختبار قبول للتثبيت والإزالة. لم يطبق فحص ICE الكامل في بيئة البناء؛ لا تعطل حماية Windows. بيانات النسخة القديمة ليست ضمن التوزيع، ويجب تغيير كلمة مرور الحساب المحلي الافتراضية قبل إدخال بيانات فعلية.

الحسابات المحلية لا تتزامن مع الويب أو أجهزة أخرى. لم توحد جميع الشاشات القديمة بصريًا. نتائج الاختبارات وتفاصيل الحدود في docs/current-delivery.ar.md وdocs/hospital-logic-review.ar.md.
