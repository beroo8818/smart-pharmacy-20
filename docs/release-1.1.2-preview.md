# Dawa 1.1.2 - Item Dictionary and Excel Registration

إصدار تجريبي محلي لويندوز 10/11 بنظام 64 بت، وليس اعتماد تشغيل للمستشفى.

- إضافة صنف للقاموس بالاسم والوحدة، وكود اختياري أو مطابق لما في Excel. الإضافة بصلاحية «تعديل تعريفات الأصناف» وتتحقق منها الخلفية.
- تعريف الصنف الجديد من معاينة ملف الفرع ثم إعادة فحص نفس الملف دون رفعه ثانية. حفظ الكميات والفترات خطوة مستقلة، ولا تضاف أرصدة أو حركات وهمية بمجرد تعريف الصنف.
- رفض تعارض الكود والاسم والوحدة، وعدم تحويل كود معروف بوحدة خاطئة أو اسم ملتبس إلى صنف جديد تلقائيًا. سحب الصلاحية يمنع الإضافة في الخادم أيضًا.
- شاشة القاموس مشتركة، مع الاحتفاظ بعرض أصناف آخر ملف محفوظ وروابط تحليلها. سجل التعريف يدخل النسخ الاحتياطية.
- في الويب، ترقية 20261029010000_item_dictionary.sql تتيح استخدام التعريف قبل أول حركة، وتشدد تطابق الكود عند الاستيراد وتنسق الإضافة والاستيراد بقفل معاملة. SQL مجهز ومختبر محليًا فقط ولم يطبق على قاعدة التشغيل الحية.

## الملفات

التحقق المعزول: 188 اختبار ويب، 18 واجهة ديسكتوب، 176 خلفية SQLite، 142 PostgreSQL، 25 استرجاع، و42 تجربة مدير ومخزن وفرعين. لا تعني هذه الأعداد اختبار تشغيل إنتاج متعدد الأجهزة.

- Dawa-Portable-1.1.2.zip: فك الضغط كاملًا ثم افتح Dawa.exe. لا تنقل exe وحده. لا تحتاج Node أو Vite عند التشغيل.
- NEW-ITEMS-ar.txt: خطوات إضافة الأصناف الجديدة بالتفصيل.
- Dawa-Guide-ar.pdf: الدليل المصور للدورة الأساسية؛ خطوات ميزة القاموس الجديدة في الملف النصي أعلاه.
- SHA256SUMS.txt: بصمات الملفات المنشورة.

لا يوجد مثبت MSI جديد في هذه الدفعة. المحمول والمثبت طريقتا توزيع للبرنامج نفسه؛ مثبت 1.1.1 لا يحتوي ميزة 1.1.2.

ملفات التوزيع نظيفة ولا تتضمن بيانات المستشفى أو النسخ الاحتياطية الخاصة. احتفظ بقاعدة بياناتك قبل أي تحديث. بيانات الديسكتوب لا تتزامن تلقائيًا مع الويب أو أجهزة الفروع. الإصدار غير موقع بشهادة ناشر؛ لا تعطل حماية Windows لتشغيله. تجربة قبول على أجهزة المستشفى وتفعيل قاعدة الويب والربط المركزي ما زالت مطلوبة.
