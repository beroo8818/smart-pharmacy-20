# مراجعة توافق الشاشات

هذه مراجعة مصدر وبرامج اختبار، وليست جولة يدويّة مكتملة لكل شاشة بكل دور على شبكة المستشفى.

| الجزء | الحالة الحالية |
| --- | --- |
| القائمة الجانبية 1.1.1 | مكون واحد وترتيب واحد: الشغل والتقارير أعلى، والإدارة والبيانات والحساب أسفل. مرشحات الصلاحيات لم تلغ |
| الصلاحيات والفروع المتأخرة ومركز التقارير والتنبيهات الرئيسية والإعدادات ودليل الخطوات | مكونات مشتركة في النسختين؛ مصادر البيانات مختلفة |
| حساب الرصيد والمنصرف والتغطية | نفس مساعدات التاريخ والحركات؛ اختبارات لمحركي الويب وSQLite |
| مساعد المخزون | مكون وقواعد مشتركة، يقرأ الرصيد الحالي ولا يستدعي خدمة ذكاء اصطناعي خارجية |
| رفع تقارير الفروع من Excel/CSV | قارئ ومعاينة وفترات مشتركة؛ خلفية الحفظ المحلية مختلفة عن PostgreSQL |
| رفع البيانات العامة وبعض التحليلات والتقارير المتقدمة | شاشات قديمة منفصلة محفوظة؛ لا يوجد ادعاء بتطابق بصري كامل |
| سجل القرارات | مكون مشترك للعرض والتصفية والتصدير. الديسكتوب يحفظ الجديد في recommendation_actions داخل SQLite ويضمه للنسخ والاسترجاع؛ الويب يستخدم جدول PostgreSQL مع ترحيل 060000 غير المطبق على القاعدة الحية |
| مركز العمل اليومي القديم | فصلت مراجعة التوزيع عن النقص الإجمالي في النسختين، وتصححت كمية شراء الويب لمنع مضاعفة نقص التوزيع. يظل شكل الصفحة وبعض توصيات الشراء وأولوية الأصناف الحرجة مختلفة. لا يعامل سجل القرار كحركة مخزون |
| تسجيل الدخول وتغيير كلمة المرور | حساب SQLite محلي مقابل حساب الويب؛ اختلاف مقصود وليس مزامنة حسابات |
| النسخ والاسترجاع | الديسكتوب نسخة قاعدة كاملة واسترجاع عند إعادة التشغيل؛ تصدير الويب ليس نسخة PostgreSQL شاملة |
| Google Sheet | الوصول المباشر يحتاج إنترنت مسموحًا؛ الملفات المحلية Excel/CSV تعمل بدونه |

قرارات الواجهة ليست حركات مخزون. الجديد يدخل نسخة SQLite. القديم المحفوظ في المتصفح لا يدخلها إلا بعد استيراد صريح من سجل القرارات بحساب مدير مخول؛ لا تحذف الأصل. المستورد يوسم تاريخيًا ولا ينسب للمدير كمؤلف أصلي. احتفظ بمجلد DawaData كاملًا عند النقل وبملفات Excel الأصلية منفصلة. توحيد التخزين لا يعني مزامنة أجهزة المستشفى.

الاختبار الميداني المتبقي موضح في network-handoff.ar.md، وحالة التثبيت وملف ZIP في windows-delivery.ar.md.
